# Number Five — plotters: evidence notes

Reviewed 1 November 2026. These are source-backed notes from saved records, not a new runtime or on-water test. Internal machine paths and runtime identities are omitted.

## Karten für vorhandene Plotter

Explore whether openly usable vector data and authored chart content can be translated to existing plotter ecosystems without treating format recognition as a finished chart product.

### Recorded results

- Converter has own cache decode to no5-chart-ir, country RX5 authoring, inspect/readback and bounded region export. Supported geometry/presentation contracts reject unsupported semantics explicitly.
  - Record: `no-android/projects/chart-converter/README.md`
  - SHA-256: `9ae0999096b595eb64c27df62ca6766a3ee9fff3ea211785accd324e4b748105`
- RX5 optimization component results do not automatically authorize replacing a general-purpose chart; native selection, queries and raster parity remain separate acceptance checks.
  - Record: `no-android/projects/chart-converter/README.md`
  - SHA-256: `9ae0999096b595eb64c27df62ca6766a3ee9fff3ea211785accd324e4b748105`
- Navionics finite prototypes:166-byte header and fixed point/line presets accepted through supplied Original readers. Own462-byte and527-byte real-cache subset containers had actual admission/readback with registered synthetic key. Automatic removable-media loading, portrayal and usable Navionics chart remain unproven.
  - Record: `no-android/projects/chart-converter/README.md`
  - SHA-256: `9ae0999096b595eb64c27df62ca6766a3ee9fff3ea211785accd324e4b748105`

### Limits

- Keep Lighthouse/RX5 and Navionics visibly unfinished.
- Do not state that any arbitrary vector format can already be converted losslessly or that physical plotter support is complete.
- Publish only own authoring/integration source and legally reusable input data; converter ability does not grant rights to someone else’s charts/OEM runtime/keys. No worldwide blanket legality conclusion.
