# Number Five source collection

Eleven component snapshots, prepared 1 November 2026. Each directory has a manifest, licence notices, build instructions and limitations. Original project working directories remain unchanged.

The large Android archive is hosted as a GitHub release asset; the remaining archives are served by the website. See [manifest.json](manifest.json) for exact file hashes and links. No APKs, private signing keys, accounts, licensed charts or real recordings are bundled. Source availability does not establish complete device, electrical or on-water acceptance.
