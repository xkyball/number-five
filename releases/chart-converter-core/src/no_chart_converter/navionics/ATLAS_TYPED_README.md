The Atlas accepts each existing strict map document directly in `maps[]`:
`no5-own-plain-layered-feature-batch/1` or
`no5-own-plain-typed-attribute-batch/1`. The outer format remains
`no5-own-plain-atlas/1`. No second map serializer or attribute implementation is
introduced. Explicit type dispatch reuses each emitter's planner and chunk stream.

All-raw Atlas plans, SHA bindings and bytes remain unchanged. Typed or mixed
inputs add `typedMapOrdinals` and a truthful explicit E/M semantic qualifier to
the Atlas plan. Typed layer presence masks, repeated physical layer codes and
all feature/stream addresses stay in the existing typed plan and are rebased by
the same Atlas offset pass. One typed-map Atlas has exactly the standalone typed
writer's bytes. No class/value table in `typed_batch.py` is expanded by this delta.

The private streamed producer is separate and unchanged. It encrypts only the
consecutive55*N Kind17 headers; lower layers, masks, attributes and vectors remain
Plain. No key registration or genuine runtime call is performed by either Python
emitter. A caller must use fresh files and verify persisted output separately.

The optional manual `collect_stream` helper accepts exactly the producer caller's
four public scalar records (ready/file/result/EOF), requiring the exact externally
bound runtime public-plan SHA. Its local output-layout comparison returns only
booleans/counts. It must run in the private execution workspace: no provider-bound
output bytes/path/hash or private register/K/P are returned. A layout/scalar match
is not an independent cipher-decryption, admission, geometry or portrayal proof.
Runtime remains responsible for matching source/provider snapshots, regular RO
inputs, public SHA pre/post, bounded capture and fresh private output. There is
no automatic Original execution, startup or deployment path.

Native source now separately qualifies explicit closed rings in forward part
order for the renderer's feature-level EvenOdd pool. This dispatcher makes no
new nautical interpretation, topology repair, point mapping or lossless attribute
claim. External adapters must account every input feature, sample, part and
attribute. Native scaled/multimap and typed actual readbacks remain distinct from
these source/software controls.
