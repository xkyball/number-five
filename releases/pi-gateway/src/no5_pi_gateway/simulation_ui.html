No5 · lokale Simulation

Nur Loopback + Bearer-Token. Änderungen überlagern ausschließlich ausgewählte HELM-/Wetterfelder. AUDIO bleibt immer echt oder unavailable. SONAR wählt nur einen bereits konfigurierten M0-/M1-Daemon; diese Seite erzeugt keine Pings.

Lokaler Zugriff

Fahrtmodell

HELM: individuell überlagern

Nicht angekreuzte Felder bleiben vom realen Adapter – einschließlich unavailable/stale.

Wetter: individuell überlagern

Nicht angekreuzte Werte bleiben reale Vorhersagewerte oder unavailable.

SONAR-Quelle

M0 = vorhandener SONAR-Simulator-Daemon; M1 = Pico-Daemon. Eine nicht provisionierte Quelle kann nicht gewählt werden.
